Blockly Games : Pip's jobs

Pip is a little helper. You do not walk the path yourself. You tell Pip what to do, then press Run and see if Pip did the job.

Sign

Write the note that tells Pip what to paint. A sloppy note changes things you wanted left alone.

Stamps

Pip already made some changes. Stamp yes on the ones you want, and put the rest back.
